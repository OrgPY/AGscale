Control plane

Separate platform defaults from app-team intent.

  1. 01

    Platform teams define the shared layer.

    Runtime images, model credentials, memory backends, context providers, skill registries, and policy defaults stay reusable.

  2. 02

    App teams request agent behavior.

    An Agent or AgentWorkflow references the platform layer and declares workload shape, skills, dependencies, and limits.

  3. 03

    Kubernetes reconciles the result.

    The controller creates Deployments, Services, optional autoscaling, status conditions, and remediation history.
